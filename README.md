# creation.anievo.id

GitHub Pages site of the AniEvo-ID organization, served at https://creation.anievo.id.

Every other repository in this organization that publishes GitHub Pages without its own custom domain
is served under this domain, at `https://creation.anievo.id/<repository>/`, for example
[rbac-evolution](https://creation.anievo.id/rbac-evolution/).

The root page only redirects to https://anievo.id/.
